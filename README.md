# Week 6 BDA

This repository contains the project files for Week 6 of the BDA coursework, including data analysis and visualisation notebooks.

## Files

- `Regression.ipynb`
- `Visualising_Data.ipynb`
- `community_health_activity_with_population.csv`
- `sexDensitiesFemale.csv`
- `sexDensitiesMale.csv`

## Purpose

The project explores community health activity data and visualisations related to population and sex-specific density patterns.

## Running the notebooks

Open the `.ipynb` files in Jupyter Notebook or JupyterLab and run the cells in order.

## Dependencies

- Python
- Jupyter Notebook / JupyterLab
- pandas
- matplotlib
- seaborn
- numpy
